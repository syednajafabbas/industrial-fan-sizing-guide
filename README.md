# Industrial Fan Sizing & Duty-Point Guide (CFM, Static Pressure & 60Hz)

Bilingual (English + Arabic RTL) engineering reference and interactive CFM / static pressure sizing microsite for **Cloud Electrical Co. (Sahab Al Kahraba Trading Establishment)** — [cloudventsa.com](https://www.cloudventsa.com/).

## Structure
- `index.html` — English (LTR) sizing guide, interactive CFM/ACH calculator, unit converter, duty-point fan selector, 60Hz Saudi power guide, FAQs, and Wikipedia CFM references.
- `ar/index.html` — Arabic (RTL) guide linking to [cloudventsa.com/ar](https://www.cloudventsa.com/ar).
- `assets/styles.css` — Responsive light/dark industrial styling matching Cloud Electrical Co.
- `assets/calculator.js` — Client-side calculator, unit converter, fan selector, and WhatsApp duty-point export.
- `sitemap.xml` & `robots.txt` — Search engine discovery files.
- `.nojekyll` — Disables Jekyll processing on GitHub Pages.

## Before Publishing on GitHub Pages
Replace `YOUR_GITHUB_USERNAME` in `index.html`, `ar/index.html`, `robots.txt`, and `sitemap.xml` with your actual GitHub username (or custom domain) so canonical, `hreflang`, Open Graph, and sitemap URLs match your live GitHub Pages URL.
